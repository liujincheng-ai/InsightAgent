# InsightAgent 项目简历内容（央国企 AI 岗）

## 项目名称

**InsightAgent——企业经营数据与知识协同分析智能体**

## 项目描述

面向企业内部经营分析场景，结合 DeepSeek 构建结构化业务数据与制度知识联合分析原型，实现可追溯的数据查询、风险预警、制度引用和经营报告。

## 技术栈

Python、FastAPI、DeepSeek、PostgreSQL、DuckDB、YAML、ChromaDB、本地中文 Embedding、RAG、Docker、Pytest

## 核心工作

1. 建立包含区域、产品、客户和 60,000 条销售事实的可重复合成数据集，使用固定随机种子和 Gold Truth 验证华东刹车系统下降、渠道贡献、客户风险与毛利变化。
2. 建设 6 份带章节号的合成企业制度，使用本地 BGE 中文 Embedding 和 ChromaDB 支持制度检索与章节引用；明确远程 DeepSeek API 的数据流转边界，不把本地向量化夸大为完全私有化。
3. 实现销售诊断、客户流失预警和经销商健康度 3 个可解释业务 Tool，将数据事实、演示规则和经营建议分层，避免将交易异常直接判定为客户流失或因果结论。
4. 使用 PostgreSQL 独立只读角色、参数化 SQL、单语句预检、脱敏 Observation、权限错误不重试和运行时凭据建立多层防线；9 类故障的分类与脱敏均达到 9/9。
5. 建立覆盖 SQL、RAG、Tool 与综合任务的 30 条冻结验收集，Pro 基线 **26/30（86.67%）**，修复候选曾达 30/30，独立首次发布复验为 **28/30（93.33%）**；制度文档和章节命中率由 **92.31% 提升至 100%**，综合任务由 **85.71% 提升至 100%**，迭代后累计 214 项自动化回归通过。
6. 将指标公式、时间口径、维度语义和歧义规则沉淀为可版本化业务词典，配套两个只读语义视图与 30 条专项评测；唯一一次 Pro 最终运行 **27/30（90%）**，高风险歧义澄清和澄清前不查库均为 **100%**。
7. 为领域 Tool 增加枚举、格式、范围和未知字段拒绝，在数据库执行前完成参数校验；首次 Pro **14/40** 暴露文本 ReAct 协议适配失败，兼容修复后同集复验 **38/40**，Flash `boundary` 选择 **99.17%**、参数有效率 **100%**；生产三链路烟测 **3/3**。
8. 建设 40 题制度检索集、4 份干扰文档与 54 组 Vector/BM25 实验；唯一 Pro 最终轮文档命中 **100%**、MRR **98.10%**、引用精度 **100%**、拒答 **5/5**、伪造引用 **0**，自动/人工事实分别为 **81.90%/92.86%**。
9. 设计统一失败分类、请求级一次恢复预算、稳定指纹断路器与 `success/failed/partial` 完成合同；从 Pro 轨迹定位 CLI 风格参数、数值字符串和跨 Tool 预算重置问题，通过无损参数归一与有界恢复将 20 题同集 Pro 恢复率由 **66.67% 提升至 91.67%**，总通过率由 **70% 提升至 90%**，有界终止 **100%**、不可恢复错误盲重试和断路后调用均 **0%**。

## 边界说明

当前是可私有化演进的单机原型，不是生产系统；V1 未实现完整 RBAC、Document ACL、多租户、高可用与审计后台。Week 2 与 Week 4 的优化结果均是查看失败后的同集修复回归，不是独立盲测；原始分数与中间失败轮均保留。

## 精简版（简历空间不足时）
