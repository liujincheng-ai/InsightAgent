# 项目经历｜上海市大数据中心 / 上海数据集团通用精简版

## InsightAgent — 企业数据与制度知识协同分析 Agent

**2026.09–至今｜核心开发者**  
**技术栈：** Python、FastAPI、ReAct、PostgreSQL、DeepSeek、RAG、ChromaDB、SSE、Docker、Pytest

面向复杂经营分析场景，构建可自主调用 SQL、领域 Tool 和知识库的 Agent，实现自然语言问数、销售诊断、风险识别、制度检索与证据化报告。

- **Agent 编排与记忆管理：** 基于 ReAct 和 `ToolPack` 设计“领域分析 → 知识检索 → 报告生成”完成契约；按 `conv_id` 隔离 Message/Plan Memory，持久化步骤、任务计划与引用，并按 Token 预算压缩长上下文、通过 SSE 输出状态，兼顾多轮连续性与执行可观测性。
- **Tool 与 Text-to-SQL：** 实现销售诊断、客户风险、经销商健康度 3 个参数化 SQL Tool；建设 YAML 业务语义层和 SQL 预检，统一同比/环比、加权毛利率及下降贡献口径，定位并修复贡献率分母导致的 **73.99% → 74.89%** 偏差。
- **证据与安全：** 将 SQL/Tool Observation 和制度章节绑定到最终回答；建立 9 类 SQL 错误反馈、单次纠正与重复调用阻断，并以单语句预检、参数化查询和 PostgreSQL 只读角色限制写操作。
- **评测闭环：** 编写真实 SSE 评测器，保存 Tool、SQL、Observation、引用与失败原因；V1 同一 30 题 Pro 由 **26/30 提升至 28/30**，语义专项集 **27/30**；Week 2 首次 Pro **14/40**，协议修复后同集复验 **38/40**，生产烟测 **3/3**，累计 **214 项回归通过**。
- **RAG 专项：** 建设 40 题与 4 份干扰文档，完成 Vector/BM25 54 组矩阵；唯一 Pro 最终轮文档命中 **100%**、MRR **98.10%**、引用精度 **100%**、拒答 **5/5**、伪造引用 **0**，自动/人工事实分别为 **81.90%/92.86%**。

> 数据与制度为合成验证资产；Week 2 复验不是独立盲测，首次 14/40 已保留；Week 3 自动与人工事实分数同时披露。
