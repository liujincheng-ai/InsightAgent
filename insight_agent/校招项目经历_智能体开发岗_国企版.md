# 智能体开发岗（国企版）

## InsightAgent——经营数据与制度知识协同分析系统

**2026.09–至今｜独立开发**

**项目背景：** 面向企业经营辅助分析场景，针对销售数据、指标口径和管理制度分散，人工取数与查阅
效率低、分析过程难追溯等问题，构建集自然语言问数、经营异常诊断、制度依据检索和报告生成于一体
的智能体原型，重点保障口径一致、访问受控、依据可查和异常可终止。

**技术架构：** Python、FastAPI、InsightAgent、ReAct、DeepSeek、PostgreSQL、RAG、中文 Embedding、
ChromaDB、YAML、SSE、Docker、Pytest

**主要职责：**

1. **经营数据标准化：** 建立销售事实及区域、产品、客户维度模型，以 YAML 统一维护指标定义、计算
   公式、单位和时间范围，并建设 PostgreSQL 只读聚合视图，解决销售额/销量、加权毛利率、贡献率
   分母及区域归属等口径混淆问题。
2. **受控智能体流程：** 基于 InsightAgent 构建 ReAct 执行链，将任务划分为数据查询、领域诊断、制度检索
   和报告生成；通过工具白名单、参数 Schema 与完成合同控制调用顺序，保证全部分析项完成后再输出，
   并将数据事实、规则判断和管理建议分层呈现。
3. **安全访问与运行留痕：** 采用参数化 SQL、独立只读账号、只读事务及单语句校验，歧义问题先澄清、
   非法参数在访问数据库前拒绝；通过 SSE 留存 Tool 参数、SQL、Observation、引用和失败原因。
   SQL 冻结集通过 **27/30**，歧义识别及“澄清前不查库”均为 **100%**。
4. **制度检索与可信回答：** 采用向量召回、BM25 对比、多意图拆分和跨文档证据扩展定位制度条款，
   建立文档/章节级引用及低证据拒答规则；文档命中率 **100%**、MRR **98.10%**、引用准确率
   **100%**，无答案场景拒答 **5/5**。
5. **异常治理与资源控制：** 对可恢复错误设置一次共享恢复预算，以失败指纹阻止重复执行；引入分层
   上下文预算及大结果持久化，保持全量结果可追溯。长上下文任务关键事实保持率 **95%**、引用准确率
   **95.45%**，平均估算输入 Token/成本下降 **50.01%/47.90%**，无上下文溢出。
