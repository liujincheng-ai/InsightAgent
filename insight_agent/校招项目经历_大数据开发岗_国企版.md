# 大数据开发岗（国企版）

## InsightAgent——经营数据标准化与智能分析系统

**2026.09–至今｜独立开发**

**项目背景：** 面向企业经营数据辅助分析，针对数据口径分散、跨部门指标理解不一致、人工取数效率低
和分析依据难追溯等问题，建设经营数据建模、指标标准管理、受控查询、制度知识检索和智能分析一体化
原型，以统一数据标准和完整执行轨迹支撑销售分析、客户风险识别及经营决策复核。

**技术架构：** Python、PostgreSQL、SQL、FastAPI、InsightAgent、DeepSeek、RAG、ChromaDB、YAML、
SSE、Docker、Pytest

**主要职责：**

1. **数据模型与验证基线：** 建立销售事实表及区域、产品、客户维度模型，基于固定种子生成 6 万条
   可复现明细；为同比/环比、加权毛利率、折扣、渠道贡献和客户风险建立标准答案，使数据问题能够
   稳定复现、定位和回归验证。
2. **指标标准与口径治理：** 使用 YAML 统一维护指标名称、业务定义、计算公式、单位、统计周期和字段
   映射，建设 PostgreSQL 只读聚合视图；增加 SQL 语义预检，防止毛利率简单平均、贡献率分母不一致
   以及交易区域与客户归属区域混淆，SQL 冻结集通过 **27/30**。
3. **受控数据服务：** 将销售诊断、客户风险和经销商健康分析封装为标准化数据 Tool，通过 Pydantic
   校验参数及返回结构；采用参数化 SQL、独立只读账号、只读事务与单语句检查，非法请求在数据库
   访问前阻断，歧义处理与“澄清前不查库”均为 **100%**。
4. **数据与制度证据协同：** 将经营指标与制度条款联合输出，通过文档/章节级引用和低证据拒答保证
   依据可核验，并将数据事实、规则判断和管理建议分层呈现；文档命中率 **100%**、MRR **98.10%**、
   引用准确率 **100%**，无答案场景拒答 **5/5**。
5. **全量追溯与质量验收：** 大查询完整结果先落盘，再向 Agent 提供 Schema、记录总量、Top-N 摘要
   及路径；建立 Gold、SQL、Observation、引用和失败原因的一体化验收链路。长上下文任务关键事实
   保持率 **95%**，平均估算输入 Token/成本下降 **50.01%/47.90%**，无上下文溢出或不可追溯结果。
