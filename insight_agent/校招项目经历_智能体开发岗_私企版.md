# 智能体开发岗（私企版）

## InsightAgent——企业经营分析智能体

**2026.09–至今｜独立开发**

**项目背景：** 面向汽车配件经营分析场景，针对业务人员查询数据库门槛高、指标口径不统一、数据分析
与制度检索割裂等问题，构建可自主完成任务拆解、工具调用、经营诊断、制度取证和报告生成的 Agent，
支持销售归因、客户风险识别、经销商健康评估及多轮追问。

**技术架构：** Python、FastAPI、InsightAgent、ReAct、DeepSeek、PostgreSQL、RAG、ChromaDB、SSE、
Pydantic、Docker、Pytest

**主要职责：**

1. **Agent Harness 与任务编排：** 基于 InsightAgent `ToolPack` 二次开发 ReAct 执行链，设计
   “任务识别—领域分析—制度检索—证据汇总—报告生成”工作流；通过工具白名单、显式完成合同和
   多工具结果合并，避免复杂任务漏调工具或取得局部结果后提前结束。
2. **Text-to-SQL 与领域工具：** 以 YAML 指标词典和 PostgreSQL 只读视图统一同比/环比、加权毛利率、
   渠道贡献等口径，将销售诊断、客户风险、经销商健康封装为 3 个确定性 Tool；增加歧义门禁、参数
   Schema 和 SQL 语义校验，SQL 冻结集通过 **27/30**，Tool 参数有效率 **100%**。
3. **RAG 证据链：** 对企业制度进行分块入库，通过向量/BM25 参数实验、多意图拆分和跨文档证据扩展
   提升召回；建立“结论—文档—章节”引用合同及低证据拒答机制，文档命中率 **100%**、MRR
   **98.10%**、引用准确率 **100%**，避免无依据生成制度结论。
4. **失败恢复与执行可靠性：** 按参数、权限、数据库、检索和模型协议对错误分类，设计请求级一次恢复
   预算、重复失败指纹和有界终止；可恢复任务成功率由 **66.67% 提升至 91.67%**，有界终止率
   **100%**，不可恢复错误不进行盲目重试。
5. **上下文与自动化评测：** 设计三档上下文预算和大结果“全量落盘、摘要入上下文”机制；基于 SSE
   轨迹自动评分任务完成度、关键事实、引用、Token、延迟和成本。20 条长链任务由 **12/20 提升至
   15/20**，关键事实保持率 **95%**，平均估算输入 Token/成本下降 **50.01%/47.90%**，平均延迟
   由 **12.376 秒降至 8.204 秒**。
