# Week 3 验收报告：RAG 检索、引用与拒答

## 结论

Week 3 工程目标已完成：冻结数据集、干扰语料、向量/BM25 对照、54 组参数矩阵、
多意图跨文档检索、结构化引用评分、无答案拒答、唯一 Pro 最终运行和逐题人工复核均
已有可审计证据。

最终轮在检索、引用和拒答指标上通过；自动事实准确率 81.90% 未达 90%，人工逐题
裁决为 92.86%。因此结论是“检索与引用合同通过，自动字符串事实评分未通过，人工
事实验收通过”，不能简化成无条件全项通过。

## 数据与实验纪律

- 40 题：15 单文档、10 多文档、10 精确条款、5 无答案。
- 24 dev 用于调优；12 test 与 4 challenge 在最终轮前未查看回答。
- 6 份正式合成制度保持不变；4 份干扰文档只进入隔离实验索引。
- 每次运行使用新目录和新索引，不覆盖失败轨迹。
- Flash 用于开发；最终配置冻结后，Pro 全量只运行一次。
- 服务端未提供可审计 Token，因此不填写调用费用。

## 参数选择

完整矩阵覆盖：

- Retriever：Vector、BM25；
- Chunk Size：256、512、800；
- Overlap：0、50、100；
- Top-K：3、5、8。

单查询矩阵中，原基线 Vector 512/50/K5 已是最优组之一：文档和章节命中均为
100%，MRR 1.0。BM25 同配置文档命中 100%、章节命中 95.24%、MRR 0.9762。
最终在该向量基线上增加确定性多意图拆分：保留原查询前三名，再从子查询结果中用
RRF 选择两个不同正式文档的证据。开发集 Coverage@5 从 93.65% 提升到 96.03%，
平均检索从 14.4 ms 增至 46.9 ms。
