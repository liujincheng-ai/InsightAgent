# InsightAgent Day 4 业务规则

本文冻结 Day 4 两个业务 Tool 的 V1 口径。制度规定与项目演示规则必须分开解释；
系统输出是经营预警，不替代客户沟通、人工核验或管理审批。

## 1. 客户风险规则

输入季度记为当前期，基准期固定为其上一季度。

| 状态 | 确定性数据条件 | 解释 |
|---|---|---|
| `suspected_churn` | 基准期销售额大于 0，当前期销售额为 0 | 疑似流失/停止采购预警，不表示已经确认流失 |
| `significant_decline` | 两期均有采购，销售额下降比例大于等于 `decline_threshold` | 大幅下滑预警，默认阈值为 50% |
| `new_customer` | 基准期销售额为 0，当前期销售额大于 0 | 新增采购，不列入风险客户 |
| `stable_or_growing` | 不满足以上条件 | 当前季度未触发本 Tool 的下降预警 |

下降贡献度为单个客户下降金额除以区域与品类范围内的总净下降额。总净下降额不为正时，
贡献度返回 `null`，避免用客户局部下降制造“区域整体下降”的错误结论。

制度依据：

- 《重点客户流失预警办法》1.2：重点客户包括 A 级客户和区域贡献前十客户；
- 2.1、2.2：数据异常只触发分级预警，不能直接当作流失事实；
- 3.1：预警后仍须核对订单、联系人、库存、价格和售后信息；
- 5：普通分析只保留必要的客户编号和经营指标。

## 2. 经销商健康度规则

只分析客户维度中 `channel=经销商` 的记录。总分为四项子分之和，范围为 0～100。

### 2.1 销售变化得分（40 分）

| 当前季度环比 | 得分 |
|---|---:|
| 大于等于 0 | 40 |
| 大于等于 -10%，小于 0 | 32 |
| 大于等于 -20%，小于 -10% | 24 |
| 大于等于 -30%，小于 -20% | 12 |
| 小于 -30% | 0 |

基准期为 0 且当前期有采购时得 40 分；两期均无采购时得 0 分。

### 2.2 活跃采购天数得分（20 分）

以当前期活跃采购天数除以上一季度活跃采购天数：

| 活跃天数比 | 得分 |
|---|---:|
| 大于等于 1 | 20 |
| 大于等于 0.8，小于 1 | 16 |
| 大于等于 0.5，小于 0.8 | 10 |
| 大于 0，小于 0.5 | 5 |
| 等于 0 | 0 |

基准期为 0 且当前期有采购时得 20 分；两期均无采购时得 0 分。

### 2.3 折扣得分（20 分）

按《汽车配件价格与折扣管理办法》2.2 使用当前季度订单行简单平均折扣率：

| 平均折扣率 | 得分 |
|---|---:|
| 不超过 8% | 20 |
| 超过 8%，不超过 12% | 14 |
| 超过 12%，不超过 15% | 8 |
| 超过 15% | 0 |

### 2.4 毛利率得分（20 分）

毛利率使用总毛利除以总销售额，并比较当前季度与上一季度：

| 毛利率环比变化 | 得分 |
|---|---:|
| 未下降 | 20 |
| 下降不超过 1 个百分点 | 16 |
| 下降不超过 2 个百分点 | 12 |
| 下降不超过 5 个百分点 | 6 |
| 下降超过 5 个百分点 | 0 |

### 2.5 风险分级

| 健康度总分 | 风险等级 |
|---|---|
| 80～100 | `low` |
| 60～79 | `medium` |
| 0～59 | `high` |

风险列表按风险等级、总分升序、当前销售影响降序、客户名称排序，保证结果稳定。

制度依据：

- 《经销商分级与考核管理制度》3.1：考核销售变化、加权毛利率、折扣与经营质量；
- 3.2：季度销售额环比下降超过 20% 触发经营预警；
- 4.2：A 级经销商触发预警后需要专项处置，不能未经核验直接降级；
- 《汽车配件价格与折扣管理办法》2.2、3.1、4.2：折扣计算口径和 8%/12%/15% 分段；
- 《2026 年度经营目标》2.2：毛利率必须按总毛利除以总销售额计算。

## 3. 规则边界

销售和活跃度分段、毛利率分段、四项权重及风险等级是 InsightAgent V1 的可解释
演示规则，不是制度原文，也不是行业统一标准。当前数据集没有回款、投诉、沟通记录、
库存和审批记录，因此 Tool 不计算或推断这些指标。
