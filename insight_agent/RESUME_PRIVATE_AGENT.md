# InsightAgent 项目简历内容（私企 Agent 开发岗）

## 项目名称

**InsightAgent——企业经营数据与知识协同分析智能体**

## 项目描述

面向汽车配件销售经营分析场景，基于 ReAct 编排层 构建结构化数据与企业制度联合分析 Agent，实现自然语言查询、销售下滑诊断、客户流失预警、经销商健康度分析、制度引用和 HTML 报告生成。

## 技术栈

Python、FastAPI、DeepSeek、PostgreSQL、DuckDB、YAML、ChromaDB、RAG、ReAct Agent、Tool Calling、SSE、Pytest、Docker

## 核心工作

1. 实现 ReAct Agent 与 Tool 调用链，复用 `@tool`、`ToolPack` 和 `ResourceManager`，实现销售诊断、客户流失预警和经销商健康度 3 个确定性业务 Tool，统一计算同比/环比、下降贡献和毛利口径。
2. 针对 DeepSeek 调用格式漂移、Tool 误选、重复 SQL 和“未执行却声称完成”，实现意图路由、Tool 顺序门禁、真实事件完成判定和窄形状受控恢复。
3. 建立 9 类 SQL 错误分类、脱敏 Observation、同步骤最多一次纠正和重复 SQL 阻断；对高风险数值从成功 Observation 确定性计算，解决 SQL 正确但答案转写错误。
4. 构建 30 条 dev/test 冻结 Benchmark，保存真实 SSE 轨迹、SQL、Tool、引用、延迟和失败原因；Pro 基线 **26/30（86.67%）**，修复候选曾达 30/30，独立首次发布复验为 **28/30（93.33%）**，其中 SQL 执行、Tool、RAG 和综合任务均为 100%；主链路严格九项稳定性由 **0/5 提升至 5/5**。
5. 建立 214 项自动化回归，覆盖业务指标、Tool 契约、路由、SQL 恢复、综合任务门禁、语义层、解析器和评分器；Ruff 检查通过。
6. 建设可配置 Text-to-SQL 业务语义层与两个只读语义视图，覆盖加权指标、时间边界、维度选择和高风险歧义；冻结 18 dev + 8 test + 4 challenge 语义集，唯一一次 Pro 最终运行 **27/30（90%）**，SQL 执行、歧义处理、澄清前不查库均为 **100%**，Day 7 语义回归 **2/2**。
7. 扩展 `FunctionTool` 参数 Schema 展示与执行前校验，建设 40 题三配置重复实验；首次 Pro **14/40** 暴露文本 ReAct 协议适配缺口，兼容修复后同集复验 **38/40**，Flash `boundary` 选择 **99.17%**、参数有效率 **100%**；生产三链路烟测 **3/3**。
8. 建设 40 题 RAG 冻结集、4 份干扰文档和 Vector/BM25 54 组矩阵；唯一 Pro 最终轮文档命中 **100%**、MRR **98.10%**、引用精度 **100%**、拒答 **5/5**、伪造引用 **0**，自动事实 **81.90%**、逐题人工裁决 **92.86%**。

## 指标使用说明

Day 7 首次完整复验冻结为 28/30，不选择性重跑。两项失败都发生在 Text-to-SQL 的最终事实完整性/贡献率口径；这也说明 LLM Agent 即使 temperature 0 仍存在路径波动。不将修复候选的 30/30 扩大为生产准确率 100%。

Week 1 使用不同的 30 条专项语义集，27/30 不能与 Day 7 的 28/30 直接作升降对比。严格结果集 76.92%、答案事实 88.46%，三个失败已公开；不把 SQL 执行 100% 写成语义准确率 100%。

Week 2 的 Flash 与 Pro 结果来自 40 题 Tool Calling 冻结集。修复后达到正式门槛，但 38/40 是查看首次 14/40 失败后的同集回归，不将其表述为新的独立盲测或生产准确率。

Week 3 的自动事实评分存在 7 条语义等价假阴性；人工复核仍确认 6 条部分事实遗漏，因此两套分数同时披露。
