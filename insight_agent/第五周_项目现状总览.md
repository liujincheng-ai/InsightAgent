# InsightAgent 第五周项目现状总览

## 一、项目定位

InsightAgent 是基于 InsightAgent 的企业经营分析智能体。项目已经完成从“可调用工具”到
“可路由、可检索、可恢复、可控制上下文成本”的五周闭环，面向销售分析、客户分析、
库存与供应链、文档制度问答以及跨工具综合分析。

## 二、第一至第五周能力地图

| 周次 | 建设主题 | 当前能力 |
| --- | --- | --- |
| 第一周 | SQL 基线与安全 | 自然语言转 SQL、歧义澄清、只读约束、结果解释和可审计执行 |
| 第二周 | 领域工具路由 | 销售、客户、库存、供应链工具选择，参数校验与边界控制 |
| 第三周 | RAG 与引用 | 文档检索、多意图问答、章节引用、低证据拒答和事实核验 |
| 第四周 | 失败恢复 | 错误分类、可恢复重试、降级输出、有界终止和恢复评测 |
| 第五周 | Context 与成本 | 分层预算、工具结果滚动预算、大结果落盘、Token/延迟/费用评测 |

## 三、当前工程闭环

用户请求进入 Agent API 后，系统先按任务类型收敛工具面，再由领域策略完成 SQL、领域工具
或 RAG 的约束生成。每轮执行前重置工具结果预算；大结果只保留受控预览进入模型上下文，
完整内容写入限定目录。SSE 事件被评测器解析为工具轨迹、上下文状态、最终答案与引用，
最后统一计算任务通过、事实保持、引用准确、延迟和估算成本。

## 四、当前质量状态

- 第一周 Pro：27/30；SQL 执行、歧义识别及澄清前不查询均为 100%。
- 第二周：解析修复后的同集 Pro 为 38/40；Flash 边界工具选择为 99.17%，参数正确率 100%。
- 第三周 Pro：文档命中 100%、MRR 98.1%、引用准确率 100%、无答案拒答 5/5。
- 第四周 Pro：同集可恢复任务从 66.67% 提升到 91.67%，有界终止 100%，盲目重试为 0。
- 第五周 Flash 正式聚合：15/20，事实 95%，引用 95.45%，平均估算输入 Token 下降
  50.01%，平均估算成本下降 47.90%，无上下文溢出。

## 五、已知边界

1. 第五周正式聚合包含透明记录的修复补跑，尚需新的完全盲测复核泛化能力。
2. Token 和费用是统一规则下的本地估算，不能等同供应商结算账单。
3. 唯一 Pro 终验为 9/20，暴露当前完成协议对模型差异较敏感。
4. 项目没有虚构 Spark、Flink、Hive 等大数据组件；大数据岗位应强调数据口径、SQL 治理、
   质量评测与可追溯链路。
5. 当前是面试竞争力级工程样例，生产化仍需补充并发压测、权限隔离、监控告警和真实账单校准。

## 六、下一阶段建议

优先建设一套不参与调参的新盲测集，随后拆分模型专属协议适配层；接入供应商 usage 与账单
数据校准估算器，并对持久化文件增加生命周期、租户隔离和清理策略。完成这些工作后，再做
并发压测和生产部署验收。
