- 正式聚合含少量补跑替换。替换范围和来源写入 `comparison.json`，主运行结果没有覆盖；
  因而结论属于“修复回归”，不是全新的独立盲测。
- Token 与费用来自本地估算，不是供应商账单；比较使用同一估算口径。
- 结果持久化只在大结果触发，本次触发率 10%，其余优化主要来自聚焦提示词、工具面收敛
  和上下文预算配置，不能将全部降幅归因于摘要压缩。
- Pro 在当前协议下表现弱于 Flash，后续应单独做模型协议适配，不应通过反复终验挑选好结果。
