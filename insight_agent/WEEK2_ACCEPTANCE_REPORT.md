## 修复范围

- `ReActOutputParser` 接受标准多行/一行式文本 ReAct、JSON ReAct、蛇形字段与全角冒号；
- 仅在存在明确 Action 时执行 Tool，不根据裸业务参数字典猜测 Tool；
- 裸 `sql` 和 `output/result` 只映射到系统级 `sql_query` 与 `terminate`；
- 未提供显式 Action 时返回可操作的格式错误；
- 补充解析器回归测试，并修正 Tool Prompt 的示例格式和数量词作用域。
