# 启明汽车配件销售有限公司 汽车配件价格与折扣管理办法

> 文档编号：QM-PRICE-2026-04
> 版本：V1.0
> 生效日期：2026-01-01
> 说明：本文件为 InsightAgent 演示使用的合成制度，不对应任何真实企业。

## 1. 目的与原则

### 1.1 目的

规范目录价格、成交折扣和例外审批，避免以无边界折扣换取短期销售额。

### 1.2 基本原则

价格决策应同时考虑客户等级、渠道、采购量、库存和毛利。任何折扣均应以系统记录的目录价格为基准，并保留审批依据。

## 2. 价格口径

### 2.1 目录价格

目录价格是产品在价格表中的未折扣单价。销售额按数量、未折扣成交单价和折扣率计算。

### 2.2 折扣率

折扣率 0.0800 表示按未折扣成交金额优惠 8%。分析平均折扣时，应说明按订单行简单平均还是按金额加权，制度监控默认采用订单行平均折扣率。

## 3. 标准折扣

### 3.1 标准范围

一般订单折扣不超过 8%。在标准范围内，客户经理可以按已批准的客户方案执行，但仍需在订单中记录折扣率。

### 3.2 特殊活动

统一促销活动必须事先明确产品、客户范围、预算和有效期。活动结束后不得继续沿用临时折扣。

## 4. 超标准折扣审批

### 4.1 申请材料

申请人应提交客户、产品、数量、目录价格、申请折扣、预计销售额、预计加权毛利率、有效期和业务理由。

### 4.2 超标准折扣审批

折扣超过标准时按以下权限审批：

1. 超过 8% 且不超过 12%，须由区域销售经理和财务经理共同审批；
2. 超过 12% 且不超过 15%，须由销售总监和财务总监共同审批；
3. 超过 15%，除销售总监和财务总监审核外，还须总经理批准；
4. 任何人员不得通过拆分订单、修改客户归属或延后录单规避审批层级。

审批通过只对申请中列明的客户、产品、数量和期限有效。

## 5. 毛利保护与复核

### 5.1 毛利校验

审批人应检查折扣后的预计毛利率。折扣导致毛利率低于该品类经营底线时，必须补充成本、库存或战略客户依据。

### 5.2 异常复核

品类平均折扣上升超过 3 个百分点且毛利率同步下降时，财务部与销售运营部应开展专项复核，区分促销、客户结构变化和违规折扣。

## 6. 记录与审计

所有超标准折扣申请、审批、订单和复核结论应能够关联。缺少审批记录的订单不得以口头授权作为合规依据。
