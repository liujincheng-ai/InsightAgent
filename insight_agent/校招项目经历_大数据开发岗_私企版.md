# 大数据开发岗（私企版）

## InsightAgent——经营数据智能分析与指标治理项目

**2026.09–至今｜独立开发**

**项目背景：** 面向汽车配件经营分析场景，针对业务取数依赖人工 SQL、指标口径分散、结构化数据与
制度文档难以联合分析等问题，建设以 Agent 为数据消费和编排层的智能分析链路，实现经营数据建模、
指标计算、质量校验、自然语言问数、制度取证和结果追溯的闭环。

**技术架构：** Python、PostgreSQL、SQL、FastAPI、InsightAgent、DeepSeek、RAG、ChromaDB、YAML、
SSE、Docker、Pytest

**主要职责：**

1. **经营数据建模：** 设计销售事实表及区域、产品、客户维表，使用固定种子构造 6 万条可复现销售
   明细；围绕销售额、销量、同比/环比、毛利、折扣和客户风险建立 Gold Facts，为指标开发、SQL
   回归和 Agent 答案校验提供统一数据基线。
2. **指标与语义层治理：** 通过 YAML 管理指标公式、单位、时间半开区间和字段映射，建设 PostgreSQL
   只读聚合视图及参数化查询；执行前校验时间范围、聚合粒度和贡献率分母，规避毛利率简单平均、
   交易区域与客户区域混用等“SQL 正确但业务口径错误”问题，SQL 冻结集通过 **27/30**。
3. **数据服务工具化：** 将销售诊断、客户风险、经销商健康分析封装为 3 个结构化 Tool，统一返回
   指标值、统计周期、单位和证据；以 Pydantic 约束输入输出，并通过只读账号、只读事务和单语句
   校验控制数据访问，Tool 参数有效率达到 **100%**。
4. **多源数据关联与追溯：** 建设制度 RAG 链路，将经营指标与管理条款关联，文档命中率 **100%**、
   MRR **98.10%**；对大查询实行“全量结果落盘、Schema/行数/Top-N 摘要入上下文”，并阻止
   `LIMIT`/排名过滤破坏全量结果，使分析结论可定位到数据和制度来源。
5. **数据质量与评测流水线：** 解析 SSE 轨迹，逐题保存 SQL、结果集、工具参数、关键事实、引用、
   延迟和失败类型，自动回归任务质量及资源消耗。20 条长链任务关键事实保持率 **95%**、引用准确率
   **95.45%**；平均估算输入 Token/成本下降 **50.01%/47.90%**，P95 延迟由 **33.75 秒降至
   15.63 秒**。
