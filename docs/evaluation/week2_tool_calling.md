## 首次验收为何失败

首次 Pro 的 24 条 Tool Selection 失败中，23 条没有形成任何可执行 Action。原始输出常见为一行式 ReAct、JSON ReAct、蛇形字段、全角冒号或裸参数字典；原解析器只可靠接受带固定英文前缀的多行文本，因此把协议可解析性和业务选择能力耦合成了一个失败指标。

修复遵守保守边界：兼容有明确 Action 的结构化表达，但不根据裸业务参数字典猜测 Tool；仅将裸 `sql`、`output/result` 映射到系统级 `sql_query`、`terminate`。同时修正 Prompt 示例与数量词作用域，避免“风险客户前 4 名”污染销售 Tool 默认参数。
